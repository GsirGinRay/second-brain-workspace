# Markdown 編輯體驗檢視

檢視範圍：任務、專案、知識的共用編輯器、舊版入口及 DOM 操作測試。
基準：[Notion 鍵盤操作](https://www.notion.com/help/keyboard-shortcuts)。
只使用合成資料，未讀取或改寫個人 vault。

## 修改前的問題

| 問題 | 使用者可見的影響 |
| --- | --- |
| Checklist 有獨立的 Enter 分支，只插入空項目 | 中間換行不會把後半段移到下一個待辦 |
| 切分只讀 selectionStart | 選取文字後按 Enter，選取內容仍留下來 |
| 多個雙 animation-frame 回呼強制把游標移到末尾 | 點選文字、換行與合併後，游標可能跳走 |
| Shift 框選攔截整個編輯器的 pointerdown | Shift 點選延伸文字選取失效 |
| Task 分支未共用文字快捷鍵 | 粗體、斜體、斜線選單等行為不一致 |
| 格式及顏色選單只處理單一區塊 | 多選後仍需逐個轉換 |
| 區塊 undo 不接管 textarea，而且空字串被當成沒有歷史 | 換行後難以直接復原，不能復原到空內容 |
| 樣式註記被解析成另一個區塊 | 清單重新開啟後顏色脫離內容 |
| 合併方向及標記處理不一致 | Delete 可能把下一段的標題／列表語法帶進正文，或遺失任務身分 |
| Shift+Enter 沒有結構化處理 | 待辦換成多行後失去勾選框與專用編輯欄位 |
| 部分任務及專案入口仍用舊版編輯器 | 同類內容有兩種操作方式 |
| 編號沒有隨中間插入／合併更新，且不完整支援 `2)` | 產生重複編號或中斷清單 |
| 注音結束後有 300ms 的 Enter 攔截區間 | 可能吃掉使用者下一次真正的換行 |
| 預覽樣式覆蓋文字顏色 | 已儲存藍色，但待辦及結構化清單仍顯示黑色 |
| 複製待辦連同識別註記一起複製 | 同一份文件可能出現重複任務身分 |

## 驗證順序

先新增實際 React DOM 操作測試，再修改程式。初始回歸測試已重現 Checklist 中間切分及選取文字換行失敗。
優先檢查三個可驗證原因：獨立 task 分支忽略游標；一般切分忽略 selectionEnd；延遲聚焦覆蓋明確游標位置。
分別以內容、選取範圍及渲染完成後的游標斷言驗證。

## 已實作

- 待辦與其他文字共用鍵盤編輯邏輯；Enter 依選取範圍切分，後半段移至新項目，游標定位在新項目開頭。
- 延續列表符號、縮排和色彩；新待辦取消勾選，原待辦保留完成狀態與識別註記。編號清單插入／合併後更新後續編號。
- Shift+Enter 在同一區塊換行。列表以標準 Markdown 可接受的 `<br>` 儲存，編輯與預覽時呈現換行，不執行任意 HTML。
- Backspace／Delete 僅在沒有選取文字的區塊邊界進行合併；保留前段格式，不跨欄位、附件、程式碼或其他追蹤任務身分合併。
- Ctrl+B、Ctrl+I、Ctrl+E 可切換選取文字的粗體、斜體、行內程式碼；列表支援 Tab／Shift+Tab 縮排，邊界 ↑／↓ 可切換編輯區塊。
- Ctrl+Z、Ctrl+Shift+Z／Ctrl+Y 共用文字與結構歷史，可復原換行、合併、轉換與空文件，並還原游標。
- Shift 點選把手選取連續範圍；Ctrl 點選把手增減多選。工具列提供批次類型及文字顏色轉換，六點選單的色彩、複製及刪除也作用於選取群組。
- 進入文字欄位即回到文字編輯；Shift 選字不再觸發框選。工具列位於內容下方，避免出現時推移框選中的區塊。
- 任務、專案與知識入口統一共用編輯器；修正樣式註記重新解析、預覽顏色及 BOM／CRLF 輸出保留。
- 附帶修正既有的附件 ArrayBuffer 與索引 nullable 欄位型別宣告，使 TypeScript 建置可通過；不改變這兩處的執行行為。

## 驗證結果

- 編輯器 65 項 DOM 操作測試通過，涵蓋中間切分、選取替換、IME、軟換行、合併、批次轉換、色彩、復原與 Markdown 識別資料。
- 真實 Chromium 瀏覽器已驗證 Checklist 中間切分與新項目游標、連續輸入和復原、段落中間刪除、選取後換行、Shift+Enter 重新開啟、批次轉換，以及實際計算後的文字色彩。
- `npm run build`：通過。仍有既有的 JavaScript bundle 大小提示。
- 完整測試共 488 項，486 項通過。兩項日曆框選失敗已用 HEAD 版本的獨立副本重現：群組拖曳預期 3 筆、實際 1 筆；框選後批次刪除等待逾時。沒有為了通過檢查改寫這兩項測試。

## 實作邊界

維持本機 Markdown 儲存與既有備份流程。此輪改善共用區塊編輯器；仍為 textarea 編輯架構，跨區塊連續文字選取與完整行內所見即所得仍未實作，不能宣稱與 Notion 完全相同。包含隱藏 Markdown 標記的預覽文字，第一次點入時仍以末尾為預設位置；一般純文字與列表則可對應點選位置。

Windows WebView2 的實體注音輸入法仍需真人驗收；自動測試覆蓋 composition 事件與時間序列，瀏覽器的程式輸入不能取代實體 IME。未建立或安裝新的桌面安裝包，也未修改個人筆記。
