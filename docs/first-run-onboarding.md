## 為什麼要改

現在第一次選資料夾會預設勾滿五包（專案、知識庫、提示詞庫、AI、模板），再疊示範檔。新資料夾因此出現：

- 還算合理：專案「開源發表」、今日任務「寫第一份教學」、收藏「寫作素材」
- 不像通用產品：收藏「股票選股分析」（作者領域漏進預設）
- 沒有教學：`90-模板/通用專案.md`、`Prompts/`、`CLAUDE.md`、`AGENTS.md` 直接落地

Notion、Linear、Todoist、Things 的第一次使用通常是：幾乎空的畫布、一份可刪的「開始使用」、在畫面裡教（空狀態），模板放圖庫而不是預設安裝。

## 這次要變成什麼

第一次選資料夾之後，預設只建立**能刪的最少示範**，並在 App 裡教操作：

1. **一個「開始使用」專案**（可改名、可刪），不是開源／選股。
2. **三則任務，用做來教**，不要再塞領域內容：
   - 完成這一則（打勾）
   - 把它排到今天／日曆（拖曳或改日期；已有可見 `⏳` `⏰` `⏱`）
   - 在任務下面寫一段筆記（Session 1 的縮排 Markdown）
3. **一則中性收藏**，例如「以後要查的資料」。不要預設股票分析。
4. **Today / 日曆 / 專案空狀態**寫人話：「新增第一個任務」「從模板建立」；模板與提示詞庫改成之後才出現，不要第一次就寫進資料夾。

勾選「建立知識架構」時：

- 預設只勾「專案管理」與「個人知識庫」。
- 「提示詞庫」「模板套件」「AI 委任」改成可選，說明「之後需要再加」。
- 提示詞範例若保留，放可選包，檔名與內容改成通用（會議紀錄、寫作大綱），不要選股。

既有檔仍不覆寫。使用者自己的 vault 不被這次改動掃過。

## 不要做

- 不要改 Session 1 的可見時間／筆記格式。
- 不要改 `second-brain-task` / `id:` 標記。
- 不要預設寫入 `CLAUDE.md` / `AGENTS.md`（AI 包改可選）。
- 不要做多步 wizard、帳號、雲端。
- 不要把教學做成必須看完的 lightbox；可跳過、可刪示範。

## 完成時

1. `npm test`（scaffold／架構測試會改）。
2. 空資料夾走一次第一次選資料夾，確認沒有股票分析、沒有預設模板檔，Today 看得到三則教學任務。
3. 一次 commit。這個 session 結束再 push。
4. 開新 session 才做下一項。
